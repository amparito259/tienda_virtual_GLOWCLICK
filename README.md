# Tienda Virtual GLOWCLICK

GLOWCLICK es una tienda online especializada en la venta de productos de maquillaje y belleza, desarrollado con arquitectura **MVC (Modelo-Vista-Controlador)** en PHP nativo, MySQL.

## Descripción del Proyecto

Este sistema permite gestionar de manera interna el inventario de cosméticos (labiales, polvos, rubores, paletas de sombras, etc.), el registro de clientes, el control de usuarios del sistema y el registro detallado de las ventas realizadas.

Le agregamos en views un archivo llamado crear.php, y haci con las demas carpetas.
